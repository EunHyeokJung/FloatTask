## 요약

- macOS 플로팅/데스크탑 오버레이 태스크 앱과 에이전트 CLI를 구현했습니다.
- 프로젝트와 작업 CRUD, 완료 재정렬, 파일 변경 반영, Google Tasks 병합을 포함합니다.

- SwiftUI/AppKit 앱
- Codable JSON 저장소와 프로세스 간 파일 잠금
- `floattaskctl` JSON CLI
- Google Tasks REST 어댑터
- 릴리스 `.app` 번들 생성 스크립트
- 제품·구조·스펙 문서와 디자인 시스템

## 검증

- `swift test`: 5개 테스트 통과
- 임시 데이터 파일에서 CLI 생성→완료→수정→삭제 왕복 통과
- Google Tasks 모의 REST 세션에서 목록 1개와 작업 2개 업로드 통과

- 실제 창에서 일반 창 → 항상 위 → 일반 창 왕복과 클릭 가능한 상태를 검증했습니다.
- 일반 모드는 앱 프로세스까지 `.regular`로 전환하고 창을 Mission Control 관리 대상으로 설정했습니다.
- 상단 채팅 버튼과 메인 창 왼쪽 바깥으로 열리는 자식 패널을 추가했습니다.
- `gpt-5.6-luna`·`xhigh` Codex 채팅에서 자연어 CRUD를 제안하고 앱이 원자적으로 검증·적용하도록 구현했습니다.
- Codex 변경 배치 롤백, 삭제 의도 검증, 실행 프로세스 취소를 포함해 `swift test` 9개를 통과했습니다.
- 숨긴 titlebar의 잔류 vibrancy 레이어가 만든 상단 반투명 띠를 제거하기 위해 메인 창을 완전한 borderless 스타일로 전환했습니다.
- `LSUIElement` 번들 플래그를 제거해 일반 모드가 LaunchServices 단계부터 Dock·Mission Control 대상인 일반 앱으로 등록되도록 수정했습니다.
- 채팅 입력 영역을 상단으로 이동하고 실행 중인 Codex 응답을 중지하는 컨트롤을 추가했습니다.
- 프로젝트·작업 데이터에 영향을 주지 않는 채팅 기록 초기화 컨트롤을 추가했습니다.
- Bloub 기반 에이전트 아바타를 추가하고 Codex JSONL 이벤트를 Thinking·Comet·Wide Eyes 상태에 연결했습니다.
- 실제 이벤트 매핑과 프로세스 취소를 포함한 `swift test` 10개를 통과했습니다.
- borderless 창 전체 드래그와 이름 입력 포커스의 경쟁을 제거하고 창 드래그를 상단 툴바로 제한했습니다.
- 프로젝트명과 작업명에 명시적 포커스 표시, 메뉴 기반 이름 변경, Enter·포커스 이탈 저장을 추가했습니다.
- SwiftUI 기본 borderless 창을 `canBecomeKey`·`canBecomeMain`을 보장하는 전용 AppKit 창으로 교체했습니다.
- 비활성 일반 창과 항상 위 창을 각각 다른 앱 뒤에서 첫 클릭한 뒤 프로젝트·Task 편집 및 JSON 저장을 실제로 검증했습니다.
- FloatTask 전용 macOS 앱 아이콘을 제작하고 10개 표준 해상도의 `.icns` 생성·번들링을 빌드 과정에 추가했습니다.
- 프로젝트·Task 편집 시 나타나던 안쪽 여백과 회색 중첩 배경을 제거해 편집 전·중·후 텍스트 좌측 기준선을 고정했습니다.
- 입력 포커스는 레이아웃을 바꾸지 않는 1pt 하단선으로 표시하고, 필드 밖 클릭 시 편집을 저장·종료하도록 창 이벤트 처리를 보완했습니다.
- 최신 앱에서 기존 Task와 새 Task 입력의 텍스트 시작점이 일치하고, 빈 영역 클릭 뒤 접근성 포커스가 입력 필드에서 창으로 이동하며 편집 표시가 사라지는 것을 확인했습니다.
- 기존 Task 편집 중 Enter를 누르면 이름 저장 후 바로 다음 줄에 새 Task 입력을 만들고 포커스를 넘기도록 키보드 연속 입력 흐름을 추가했습니다.
- 최신 앱에서 첫 번째 Task에 Enter를 입력한 뒤 두 번째 Task 앞에 새 입력 행이 삽입되고 접근성 포커스가 자동 이동하는 것을 실제 화면으로 확인했습니다.
- Hover 중 Enter를 누를 때 삭제 버튼의 조건부 삽입과 포커스 전환이 겹치지 않도록 버튼 영역을 고정하고, 기존 제목 저장을 새 입력 행 생성보다 먼저 완료하도록 순서를 보강했습니다.
- 격리된 임시 데이터에서 `할일 준비`로 실제 제목을 수정하고 마우스를 행 위에 둔 채 Enter를 입력해, 기존 제목이 유지되고 다음 입력 행만 생성·포커스되는 것을 확인했습니다.
- 프로젝트 생성 직후 이름 전체를 선택하고 포커스하도록 생성 요청과 프로젝트 입력 행을 연결했으며, 더보기·컨텍스트 메뉴·삭제 확인창·툴팁 문구를 영어로 통일했습니다.
- 격리된 데이터에서 Add Project 직후 `Project` 전체 선택, 첫 타이핑으로 `Focus Test` 교체, `Rename`·`Delete Project` 메뉴와 영어 삭제 확인창을 실제 화면으로 검증했습니다.
- 채팅 입력 영역을 패널 하단으로 이동하고 대화 목록이 그 위의 확장 영역을 채우도록 수정했습니다. 입력 텍스트는 입력창 내부 상단 정렬을 유지합니다.
- Bloub 아바타를 채팅 헤더에서 제거하고 Luna 응답 말풍선 왼쪽으로 이동했습니다. 응답 생성 중에는 대화 목록 맨 아래에 실제 Codex 상태 애니메이션을 표시하고, 완료된 응답에서는 아바타를 정지해 불필요한 동시 애니메이션을 방지했습니다.
- 요청에 따라 Bloub 아바타를 다시 채팅 헤더로 되돌렸습니다. 변경 요청에서는 모델의 제안·예고 문장을 표시하지 않고 앱이 검증·저장한 결과만 대화에 출력하도록 수정했습니다.
- 긴 Task 제목이 행 너비에서 그대로 잘리지 않도록 비편집 표시 계층에 한 줄 끝 말줄임표를 적용했습니다. 기존 입력 필드는 같은 위치에서 클릭·포커스·Enter 흐름을 유지하며 전체 제목은 Hover 도움말로 확인할 수 있습니다.
