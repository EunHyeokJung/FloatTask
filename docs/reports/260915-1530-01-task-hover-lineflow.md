# 작업 기록 - Task Hover 줄 흐름 보정

- 일시: 2026-09-15 15:30 (Asia/Seoul)
- 작성자: Austin Jung
- 에이전트: Codex
- 작업 유형: 버그 수정

## 요약

- 긴 Task를 Hover로 펼칠 때 첫 줄 끝의 한글 단어가 통째로 다음 줄로 이동하던 현상을 수정했습니다.
- Hover 전후 제목의 가용 너비를 유지하고, 기존 첫 줄 글자는 남겨 둔 채 말줄임표 뒤 내용만 자연스럽게 이어지도록 변경했습니다.

## 변경 범위

- 확장 상태의 표시용 제목에 문자 단위 줄바꿈 지점을 추가했습니다.
- 저장되는 Task 제목, 편집 필드 값, 접근성 값에는 표시용 줄바꿈 문자를 포함하지 않습니다.
- 제품 스펙과 디자인 시스템에 첫 줄 유지 규칙을 명시했습니다.

## 주요 변경 파일

- `Sources/FloatTask/OverlayView.swift`
- `docs/02-specs.md`
- `design-system/floattask/MASTER.md`

## 검증

- `swift test`: 12개 테스트 통과
- 격리된 `FLOATTASK_DATA_FILE`과 별도 검증 앱에서 `터치할 때마다 좌측 슬라이드 리스트가 움직이는 현상` 제목을 확인했습니다.
- 확장 전 첫 줄 끝의 `움`이 확장 후에도 첫 줄에 남고, 후속 글자와 다음 Task가 같은 폭 안에서 자연스럽게 배치되는 것을 화면으로 확인했습니다.
- 접근성 트리에는 줄바꿈 문자가 없는 원래 Task 제목 전체가 유지되는 것을 확인했습니다.

## 리스크/이슈

- 표시용 문자열에만 보이지 않는 줄바꿈 지점을 사용하며 저장 데이터와 편집 동작에는 영향을 주지 않습니다.
