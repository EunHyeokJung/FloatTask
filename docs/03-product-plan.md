# 3) 제품 기획

## 목적

FloatTask는 화면 한쪽에 계속 띄워 두고 가장 가까운 작업만 빠르게 확인·완료하는 개인용 macOS 태스크 패널입니다. 복잡한 메타데이터 대신 `Project → Task` 구조만 제공합니다.

## 대상

- 작업 중 컨텍스트 전환 없이 다음 행동을 확인하려는 개인 사용자
- 동일한 태스크 목록을 읽고 수정해야 하는 Codex 같은 로컬 에이전트

## MVP 범위

- 프로젝트 생성, 이름 변경, 삭제
- 작업 생성, 이름 변경, 완료/재개, 삭제
- 완료 작업의 기본 목록 자동 숨김, 프로젝트별 완료 개수 표시
- 채팅과 같은 스타일의 전체/프로젝트별 완료 목록 패널과 최근 완료순·추가한순 정렬, 재개
- 모든 Space에서 동작하는 항상 위/일반 창 전환
- 메인 창 크기 조절과 위치·크기 기억, 밝은/어두운 외관 대응
- 파일 변경 자동 반영
- 에이전트용 CRUD CLI와 JSON 출력
- 상단 채팅 버튼과 메인 패널 왼쪽 바깥으로 열리는 Codex 채팅
- 자연어로 프로젝트/작업 생성, 이름 변경, 완료/재개, 삭제
- 영문 UI와 분리된 봇 답변 언어 설정(Korean / English), 선택 유지
- 메인·채팅에서 여는 최소 Settings: 메뉴 막대 표시, 항상 위, 답변 언어. 선택 즉시 반영·저장
- 메뉴 막대 아이콘 클릭으로 메인 창과 열린 보조 패널 표시/숨김 전환, 대화·입력 보존
- 실제 Codex 활동에 맞춰 변하는 Bloub 기반 에이전트 아바타
- access token 기반 Google Tasks 양방향 병합

## 성공 기준

- 앱과 `floattaskctl`의 변경이 동일한 JSON 저장소에 반영됩니다.
- 프로젝트와 작업의 핵심 CRUD가 마우스와 키보드 모두에서 완료됩니다.
- 항상 위 모드와 일반 앱 모드를 전환해도 창이 접근 가능하고 편집 상태가 유지됩니다.
- Codex 변경은 구조화된 액션 검증과 원자적 저장을 통과한 경우에만 반영됩니다.
- 모션 감소, VoiceOver 레이블, 밝은·어두운 외관에서도 핵심 기능을 사용할 수 있습니다.

## 핵심 흐름

1. 앱 실행 시 마지막 창 위치와 태스크 파일을 복원합니다.
2. `+`로 작업을 추가하고 원형 체크 컨트롤로 완료합니다.
3. 행 또는 프로젝트 메뉴에서 이름 변경과 삭제를 실행합니다.
   완료한 작업은 기본 목록에서 사라지며 프로젝트의 완료 개수나 헤더 체크 버튼으로 이력을 확인하고 재개합니다.
4. 에이전트는 `floattaskctl`로 같은 데이터를 조회·수정합니다.
5. 사용자는 채팅에서 자연어로 프로젝트와 작업을 조회·수정합니다.
6. 사용자가 토큰을 제공한 경우 `floattaskctl google sync`로 Google Tasks와 병합합니다.

## 비범위

- 팀 권한, 담당자, 댓글, 첨부 파일
- 우선순위, 태그, 칸반, 캘린더
- 백그라운드 OAuth 토큰 갱신
- Google 측 삭제 자동 전파
